## 1. 需求与已确定的业务规则

机器人需要在 QQ 群聊和单聊中处理订单截图及文字，记录订单号、店铺、下单日期、下单金额、实付款、订单状态和退款，统计同一客户的累计消费，自动生成 Excel，并提供消费变更话术和可选 AI 陪聊。

已确认的规则：

- 累计有效消费按 **实付款 − 累计已到账退款金额** 统计，金额以整数分计算。
- 待付款、已取消、已退款订单计零；待发货、待收货、已完成订单按净实付计入；退款申请不等于退款到账。
- 退款金额表示累计已到账额，不是本次退款增量。重复提交不能重复扣减。
- 订单以“店铺 + 订单号”识别，长订单号和前导零按文本保存。
- 每 14 天检查全部已登记订单。没有最新权威数据时保留待核对状态。
- 用户曾提到有电商查询接口，后续确认目前没有可提供的接口文档，因此当前按“接口尚不可接入”处理。
- 群聊先使用 @机器人触发；群聊与单聊身份需管理员核验后绑定，不按昵称或假设 OpenID 相同自动合并。

## 5. 当前部署选择与待确认点

### 5.1 选定路线：WebSocket

此前讨论过公网 IP HTTPS，但用户随后提供的 QQ 后台截图明确显示“当前为：WebSocket”，并可在 WebSocket 与 Webhook 间选择。因此当前路线改为 **Docker 运行机器人，主动连接 QQ 网关**：

```text
机器人服务器 → QQ 鉴权/网关地址 API（出站 HTTPS）
机器人服务器 → QQ 网关（出站 WSS，接收群聊/单聊事件）
收到事件 → SQLite 持久队列 → 订单识别/账本/Excel/话术
机器人服务器 → QQ 消息 API（出站 HTTPS，发送回复）
管理员电脑 → SSH 隧道 → 127.0.0.1:8000 管理接口
```

WSS 的服务器证书由 QQ 提供，本程序使用系统 CA 验证；**无需给自己的 IP 或域名申请证书，无需公网 HTTPS 回调，无需为机器人接收事件开放入站 443，也无需为此改动现有 Nginx。** 服务端仍需可靠的出站网络与长期运行环境。

### 5.2 官方资料差异与实现边界

- 旧官方事件文档、旧 SDK README 的 WebSocket 下线提示与当前后台及腾讯新 Node.js SDK 存在差异。此前把 Webhook 作为唯一接入路线的判断已修正，以用户当前后台和实际联调为准。
- 项目已增加 `qqbot/gateway.py`，直接按网关协议接收事件，复用同一业务队列。原 Webhook 能力作为可选方式保留。
- 默认只请求群/单聊 intent 位 `33554432`，不默认申请所有事件权限；全量群消息仍以账号实际权限为准。
- 支持一个连接、一个分片。若网关要求多个分片，当前实现会报告 `multiple_shards_required` 并停止，需要扩展后再运行。
- 鉴权或权限失败、账号/网关不可用、重试预算耗尽会在 `/admin/status` 的 `gateway` 中报告，不能只看 HTTP 健康检查就认为 QQ 已在线。
- 后台任务必须长期运行；暂停进程、休眠或网络中断会影响接收，已实现重连和恢复，但实际恢复范围仍受 QQ 网关保留时间限制。

### 5.3 白名单、管理访问及域名

QQ 后台服务器 IP 白名单应填调用 QQ API 和连接网关时的实际公网出口 IP，部署时核实是否为 `43.139.142.142`。当前尚未确认用户已添加该条 IP；后台截图提示未设置时允许所有来源，配置后限制到名单内。

管理 API 保持在云服务器 `127.0.0.1:8000`，可用 SSH 端口转发访问，例如：

```powershell
ssh -N -L 18000:127.0.0.1:8000 ubuntu@43.139.142.142
```

随后访问本机 `http://127.0.0.1:18000/docs`，仍需 ADMIN_TOKEN。这样管理入口也无需公开域名和证书。

已有 `iwg.wang` 的备案拦截是独立问题，WebSocket 不会修复现有网站。正式运营的账号权限、平台审核和适用备案要求仍按实际服务确认。

### 5.4 证书与托管入口方案的定位

IP + Let's Encrypt、第三方 HTTPS 隧道或托管函数 URL 都是未来改用 Webhook 时的备选，当前不再列为部署前置任务。若选 Webhook，仍要验证公网 HTTPS、平台回调地址、验签和数据持久性；不能把普通 HTTP 或关闭证书校验当成替代。

- QQ 官方文档注明主动推送能力于 2025-04-21 起停止提供。当前按有效回复窗口发送，窗口外保存话术等待下次联系；不能承诺后台任务发现变更后随时主动私发。
- 文档所列群聊回复窗口为 5 分钟、单聊 60 分钟，每条消息最多 5 次回复；项目使用更保守的窗口，仍需真实账号确认实际限制。
- 缺少电商接口时，截图不能证明之后发生的退款或收货变化。
- 当前只支持人民币；未知状态、金额冲突和跨客户归属不能随意合并。
- Excel 是数据库快照，直接编辑 Excel 不回写账本。
- 当前部署仅支持单进程、单副本 SQLite；不可直接扩容为多个 worker 或多副本。
- 云服务器已有业务，后续使用独立目录和容器，并在实际变更前检查冲突与回退方式。
